# E2E 测试说明

## 概述

本目录包含 OpenIM 客户端的端到端（E2E）测试，用于测试真实的消息发送、群聊、离线消息等功能。

## 测试结构

```
tests/
└── e2e/
    ├── mod.rs              # 模块定义
    ├── fixtures.rs         # 测试固件和配置
    ├── helpers.rs          # 测试辅助函数
    ├── message_test.rs     # 单聊消息测试
    ├── group_test.rs       # 群聊测试
    └── offline_test.rs     # 离线消息测试
```

## 运行测试

### 前置条件

1. 确保本地 OpenIM 服务端已启动并运行
2. 确保测试用户已注册（默认使用手机号：17764338283, 17764338284, 17764338285）
3. 确保测试用户之间已添加为好友（用于单聊测试）

### 运行所有 E2E 测试

```bash
cargo test --test e2e -- --ignored
```

### 运行单个测试

```bash
# 单聊消息测试
cargo test --test e2e test_send_single_chat_message -- --ignored

# 群聊测试
cargo test --test e2e test_send_group_message -- --ignored

# 离线消息测试
cargo test --test e2e test_offline_message -- --ignored
```

### 运行测试（不忽略）

如果要去掉 `#[ignore]` 标记，可以直接运行：

```bash
cargo test --test e2e
```

## 测试说明

### 1. 单聊消息测试 (`message_test.rs`)

测试两个用户之间的单聊消息发送和接收。

**测试流程：**
1. 登录发送者和接收者
2. 建立 WebSocket 连接
3. 发送者发送文本消息
4. 验证接收者收到消息
5. 验证消息内容正确性

### 2. 群聊测试 (`group_test.rs`)

测试群聊消息发送和接收。

**注意：** 此测试需要预先创建群组，或者使用已有的群组 ID。可以通过 OpenIM API 创建群组，或者手动创建后使用群组 ID。

**测试流程：**
1. 登录发送者和接收者
2. 建立 WebSocket 连接
3. 发送者发送群聊消息
4. 验证接收者收到群聊消息
5. 验证消息内容正确性

### 3. 离线消息测试 (`offline_test.rs`)

测试离线消息的接收。

**测试流程：**
1. 发送者登录并连接
2. 接收者不连接（模拟离线状态）
3. 发送者发送消息给接收者
4. 接收者登录并连接
5. 验证接收者收到离线消息
6. 验证消息内容正确性

## 配置

测试配置在 `fixtures.rs` 中定义，默认配置：

- API 地址：`http://localhost:10002`
- WebSocket 地址：`ws://localhost:10001`
- 平台 ID：`5`

可以通过修改 `TestConfig` 来更改配置。

## 日志

测试运行时会输出详细的日志信息，包括：
- 登录状态
- 连接状态
- 消息发送和接收
- 错误信息

日志级别可以通过环境变量 `RUST_LOG` 控制：

```bash
RUST_LOG=debug cargo test --test e2e -- --ignored
```

## 故障排查

1. **连接失败**：检查服务端是否运行，端口是否正确
2. **登录失败**：检查测试用户是否存在，密码是否正确
3. **消息接收超时**：检查网络连接，增加超时时间
4. **群聊测试失败**：确保群组 ID 正确，用户已加入群组

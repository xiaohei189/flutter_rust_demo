> 状态：产品基线，待团队评审
>
> 更新时间：2026-11-01
>
> 范围：普通群 / 话题群双模式、话题首页、话题详情、订阅、未读、置顶、关闭、撤回、任务、搜索和管理能力
>

## 1. 文档目的

本文档把飞书实机截图、项目内已有分析稿和当前产品设计整理成可评审、可验收的话题群基线。

文档区分三类信息：

- **实机已确认**：飞书真实截图中可以直接看到的行为。
- **产品规则**：本项目为实现真实可用的产品而确定的行为，不声称全部与飞书一致。
- **待实测**：需要多账号、不同角色和真实操作才能确认的竞品细节。

## 2. 竞品证据

### 2.1 已确认事实

以下行为由 2026-11-01 和 2026-09-12 的飞书 Android 实机截图确认：

1. 创建群组页可以直接选择群模式，当前值为“话题”。
2. 群模式页提供“对话 / 话题”两个选项、解释文案和页面预览。
3. 对话模式按发送先后顺序展示消息。
4. 话题模式以话题卡片为主要内容单位。
5. 一个话题群可以包含多个话题。
6. 话题首页有“全部 / 我订阅的”两个视图。
7. “全部”视图会显示话题卡片以及创建群、修改群名等系统事件。
8. “我订阅的”视图只显示已订阅话题，不显示群系统事件。
9. 话题卡片包含作者、时间、正文、回复预览和底部操作栏。
10. 话题底部操作栏包含点赞、回复、分享、订阅。
11. 已订阅话题使用填充书签图标，未订阅状态使用带加号的书签图标。
12. 回复较多时显示“查看更早 N 条回复”和最近回复。
13. 话题更多菜单包含 Pin、置顶话题、翻译、关闭话题、撤回话题、编辑话题、添加任务。
14. Pin 和置顶话题使用不同入口，是两种独立能力：Pin 进入独立的已 Pin 话题集合，置顶话题出现在话题群顶部。
15. 话题群首页右下角有发布话题按钮。

### 2.2 待实测

以下规则不能仅凭现有截图确认：

- 创建者和回复者是否自动订阅。
- 订阅具体控制哪些通知。
- Pin 和“置顶话题”的准确作用域和权限。
- 顶部数字是群未读数还是其他统计。
- 进入话题后何时更新已读位置。
- 群列表角标统计未读话题数还是未读回复数。
- 普通成员、话题作者、管理员、群主的完整权限矩阵。
- 关闭话题后是否允许作者或管理员回复。
- 撤回根消息后已有回复如何展示。
- 对话模式与话题模式切换后旧消息如何归类。
- 多设备上订阅、Pin、关闭和已读状态的同步时延。
- 非群成员打开分享链接时的表现。

这些规则必须在开发前通过真实租户、不同角色和多设备验证。

## 3. 产品定义

### 3.1 产品边界

话题群仍然是群，不是新群、新会话类型或新成员体系。

```text
群
├─ 群成员、角色、公告、头像、禁言
├─ 群系统事件
└─ 0…N 个话题
   ├─ 1 条根消息
   ├─ 0…N 条回复
   ├─ 订阅 / 未读
   ├─ Pin / 置顶
   ├─ 任务
   └─ 开放 / 关闭 / 撤回状态
```

对话和话题是同一个群的两种协作模式：

- 对话模式：消息是基本单位。
- 话题模式：话题是基本单位，消息是话题内容。

### 3.2 核心原则

- 一个话题群可以包含多个话题。
- 一个话题只有一条根消息，但可以有多条回复。
- 回复采用平铺时间线，允许引用，不建立无限嵌套回复树。
- 话题是独立业务对象，不是普通消息的视觉标签。
- 群成员、权限、媒体上传、消息送达和撤回继续复用群聊能力。
- 订阅、未读、Pin、关闭、任务和搜索必须具备服务端状态。

## 4. 信息架构

```text
消息列表
└─ 话题群会话
   ├─ 话题群首页
   │  ├─ 全部
   │  ├─ 我订阅的
   │  ├─ 搜索
   │  └─ 管理入口
   ├─ 发布话题
   ├─ 话题详情
   │  ├─ 根消息
   │  ├─ 回复列表
   │  └─ 回复编辑器
   ├─ 置顶话题管理
   ├─ 已关闭话题管理
   ├─ 任务关联
   ├─ 历史消息
   └─ 群设置
```

## 5. 群模式

### 5.1 创建群

创建群时选择：

- 对话。
- 话题。

话题模式说明文案：

> 发布话题，在群内开展讨论。

创建完成后直接进入对应模式：

- 对话进入普通聊天详情。
- 话题进入话题群首页。

### 5.2 模式切换

群主或管理员可以切换群模式。

切换不删除历史数据：

- 对话切换话题：旧消息保留为历史消息，不自动生成话题。
- 话题切换对话：根消息和回复按时间顺序展示。
- 再次切回话题：既有话题关系继续保留。

群记录模式切换时间和切换点，用于区分没有话题归属的历史消息。

### 5.3 会话列表

一个群在消息列表中只出现一次。

话题群需要：

- 话题群标识。
- 会话置顶。
- 未读角标。
- @我 标记。
- 免打扰。
- 归档。
- 最新话题活动摘要。

最新摘要示例：

- 张三发布了话题：官网地址需要更新。
- 李四回复了话题：今晚发布安排。

## 6. 话题群首页

### 6.1 页面结构

从上到下：

1. 返回按钮。
2. 群未读或其他状态数字。
3. 搜索入口。
4. 更多菜单。
5. 群头像、群名、成员数。
6. 分享按钮。
7. 全部 / 我订阅的。
8. 置顶话题。
9. 普通话题卡片列表。
10. 发布话题按钮。

### 6.2 全部

“全部”展示：

- 群内有效话题。
- 置顶话题。
- 已关闭话题。
- 创建群、修改群名等系统事件。

系统事件不是话题，不参与订阅筛选。

### 6.3 我订阅的

“我订阅的”展示当前用户主动订阅的话题：

- 不展示群系统事件。
- 已关闭话题仍保留并显示关闭状态。
- 撤回话题从普通列表移除。
- 取消订阅后立即从该列表移除。

### 6.4 排序

默认顺序：

1. 群级置顶话题。
2. 最近活动时间倒序。
3. 活动时间相同按话题创建时间或稳定话题 ID 倒序。

新增回复和重开话题更新活动排序依据；Pin 进入独立集合，不改变群首页置顶排序。

## 7. 话题卡片

### 7.1 内容

- 作者头像。
- 作者昵称。
- 创建时间。
- 更多菜单。
- 正文摘要。
- 图片、文件、链接等内容预览。
- 最近回复预览。
- “查看更早 N 条回复”。
- 状态：已订阅、已 Pin、已关闭、有未读、@我。

### 7.2 底部操作

从左到右：

1. 点赞。
2. 回复。
3. 分享。
4. 订阅。

订阅使用书签语义：

- 空心带加号：未订阅。
- 填充或勾选：已订阅。

### 7.3 回复摘要

- 回复较少时直接展示最近回复。
- 回复较多时显示“查看更早 N 条回复”。
- 卡片不强制展示总回复数字。
- 最近回复需要展示发送者和内容摘要。

## 8. 发布话题

### 8.1 编辑器

支持：

- 文本。
- Markdown / 富文本。
- 图片、视频、语音、文件、位置、名片。
- @成员、@所有人。
- 表情和引用。
- 草稿。
- 订阅开关。

### 8.2 发布

根消息发布成功后创建话题。

发布结果：

- 本地先显示发送中话题。
- 服务端确认后进入全部话题。
- 创建者默认可订阅。
- 话题详情展示根消息。
- 发送失败保留草稿和附件。
- 重复发送必须幂等。

## 9. 话题详情

### 9.1 结构

- 顶部返回、状态和更多。
- 根消息：作者、时间、正文、附件、编辑状态。
- 根消息操作：点赞、订阅、分享、更多。
- 回复列表。
- 新消息分割线。
- 回复编辑器。

### 9.2 回复

支持全部现有消息能力：

- 文本、Markdown、媒体、文件、位置、名片。
- @成员和 @所有人。
- 引用回复。
- 表情回复。
- 输入状态。
- 失败重试。
- 更早回复分页。

### 9.3 阅读状态

- 进入话题记录已读位置。
- 停留在话题内时持续更新。
- 退出前补写阅读位置。
- 多设备同步。
- 支持标记已读和标为未读。

## 10. 话题操作

### 10.1 点赞

- 支持点赞和表情。
- 展示数量与用户列表。
- 跨端同步。
- 撤回话题后不再允许新增。

### 10.2 订阅

- 任一有查看权限的成员可以订阅。
- 创建者默认可订阅。
- 回复者是否自动订阅待竞品实测后确定。
- 订阅影响“我订阅的”和通知。
- 订阅不改变查看权限。

### 10.3 Pin

- Pin 进入独立的“已 Pin 话题”集合，不从语义上等同于置顶到群首页顶部。
- 默认所有成员可 Pin；群设置可以限制仅群主和管理员可执行 Pin。
- Pin 与“置顶话题 / 会话置顶”分开存储。

### 10.4 置顶话题

与 Pin 独立：

- 置顶话题进入话题群顶部；Pin 进入独立的已 Pin 话题集合。
- 默认所有成员可置顶；群设置可以限制仅群主和管理员置顶。
- 限制后，普通成员取消已置顶话题时只改变自己的客户端展示，不影响其他成员；再次点“置顶话题”可恢复自己客户端中的展示。
- 取消其中之一不能同时清除另一个状态。

### 10.5 添加任务

- 从话题创建任务。
- 设置负责人、截止时间和优先级。
- 任务与话题双向关联。
- 任务完成不自动关闭话题。
- 一个话题可以关联多个任务。

### 10.6 关闭话题

- 关闭表示讨论结束。
- 历史内容仍可查看、搜索和分享。
- 禁止新增普通回复。
- 有权限用户可以重开。
- 关闭和重开产生系统消息。

### 10.7 撤回话题

- 撤回根消息。
- 根消息内容和附件不可访问。
- 不允许继续回复。
- 普通列表不再展示。
- 深链显示撤回墓碑。
- 已有回复和审计记录的展示规则待竞品实测。

### 10.8 编辑话题

- 作者可以编辑根消息。
- 编辑后更新卡片摘要、搜索索引和通知摘要。
- 展示“已编辑”标记。

### 10.9 分享

- 分享到应用内其他会话。
- 复制话题链接。
- 分享卡片包含群名、话题摘要、作者、回复状态。
- 非成员不能直接读取话题正文。

## 11. 未读与通知

### 11.1 未读

- 话题维护独立阅读游标。
- 自己的回复不计入自己的未读。
- 群列表角标由话题服务提供。
- @我 单独标记。
- 进入话题后更新已读。
- 支持全部标为已读。

具体角标口径待竞品实测，产品侧需要预留以下两种能力：

- 未读话题数。
- 未读回复数。

### 11.2 通知

至少覆盖：

- 新话题。
- 已订阅话题的新回复。
- @我。
- @所有人。
- 话题关闭、重开、撤回。
- 任务分配和状态变化。

通知受群免打扰、用户全局设置和话题订阅共同影响。

## 12. 搜索

搜索范围：

- 话题正文。
- 回复正文。
- 作者。
- 附件文件名。
- 任务名称。
- 已关闭话题。

结果按话题聚合，并支持定位到根消息或具体回复。

筛选：

- 全部 / 我订阅的。
- 作者。
- 时间范围。
- 有附件。
- 有任务。
- 开放 / 已关闭。

## 13. 群设置

话题群设置需要包含：

- 群模式。
- 谁可以发布话题。
- 谁可以回复。
- 默认订阅策略。
- 未读口径。
- 话题通知策略。
- 置顶话题管理。
- 已关闭话题管理。
- 历史消息入口。
- 群成员、公告、名称、头像、禁言、转让群主、解散群。

## 14. 权限

以下是产品基线，部分操作需要竞品实测校准：

| 发布话题 | 按群设置 | 按群设置 | 允许 | 允许 |
| 回复 | 按群设置和话题状态 | 按群设置和话题状态 | 允许 | 允许 |
| 订阅 | 允许 | 允许 | 允许 | 允许 |
| 点赞 | 允许 | 允许 | 允许 | 允许 |
| 编辑根消息 | 禁止 | 允许 | 禁止 | 禁止 |
| 关闭 / 重开 | 禁止 | 允许 | 允许 | 允许 |
| 撤回话题 | 禁止 | 允许 | 允许 | 允许 |
| Pin | 按群设置 | 按群设置 | 允许 | 允许 |
| 置顶话题 | 按群设置，受限时仅影响个人视图 | 按群设置，受限时仅影响个人视图 | 允许 | 允许 |

## 15. 话题状态

```text
草稿
  ↓
发送中
  ↓
开放
  ├─关闭→ 已关闭 ─重开→ 开放
  └─撤回→ 已撤回
```

补充规则：

- 草稿和发送中只对发送者可见。
- 已关闭可查看、搜索、订阅，但不能新增普通回复。
- 已撤回不能回复，从普通列表隐藏。
- 群解散后话题不可访问。
- 退群或被踢后失去访问权限。
- 状态修改需要版本号，防止关闭和回复并发冲突。

## 16. 验收标准

- 一个群可以创建和展示多个话题。
- 全部视图包含话题和系统事件。
- 我订阅的只包含已订阅话题。
- 普通群和话题群可以按模式切换并保留历史。
- 话题卡片支持点赞、回复、分享、订阅和更多菜单。
- Pin 与置顶话题是两个独立状态。
- 发布、回复、编辑、撤回、关闭、重开在多端一致。
- 订阅和阅读位置在多端一致。
- 非成员无法读取话题内容。
- 消息回调丢失后话题索引可以自动对账恢复。
- 话题分页查询不依赖逐话题拉取消息。
- 根消息、回复、任务和通知支持深链。

### 16.1 当前实现状态（2026-11-02）

当前版本已经具备可真实联调的核心闭环：

- 普通群与话题群共用群会话，模式可双向切换；旧普通消息不追溯成话题，切回话题时原话题仍保留。
- 多话题发布、回复、订阅、未读、阅读位置、Pin、关闭、重开、撤回、作者编辑、Reaction、任务和搜索已接入真实服务端。
- 发布和回复复用群聊编辑器，支持 Markdown、@、引用、图片/多图、视频、语音、文件、位置和名片；草稿可恢复。
- 分享支持复制深链与发送话题卡片，卡片可点击回到话题详情；深链覆盖前台、后台和登录后消费。
- 服务端具备话题索引持久化 outbox、重试、死信保留和最近 7 天消息幂等对账；服务重启后可继续修复索引。
- 订阅、阅读、任务分配和控制操作通过群内 online-only 事件实时同步，并通过 `targetUserID` 隔离个人事件。
- 搜索已支持关键字、作者、创建时间、开放/关闭、附件、任务和 Pin 筛选，并使用游标分页。
- 通知中心已升级为服务端持久化通知 + 客户端本地投影，覆盖新话题、订阅回复、@我、状态、编辑和任务事件，支持全局免打扰与全部已读同步。
- 2026-11-02 已在本地源码构建并重新创建的 OpenIM 服务端镜像上跑通持久通知、成员权限、Pin/附件/@我组合搜索与死信管理的真实双用户 E2E。
- 话题群设置已支持成员发布/回复权限、首次查看自动订阅和新话题/回复通知策略，并由服务端校验群主/管理员权限。
- 话题卡片支持 @我 状态；已关闭话题、Pin 管理和只读历史消息已有独立入口。
- Pin 与群级置顶话题已拆分：Pin 进入独立列表，置顶话题参与群首页置顶排序；群设置可分别限制成员操作，普通成员的个人取消置顶通过 `topic_user_states.group_pinned_hidden` 隔离。
- 话题群首页视觉已对齐飞书：普通页面继续使用品牌蓝，话题群按群展示独立群头主题色；群头、白色内容面板、Tab、全宽话题卡、四等分操作栏和圆形发布按钮均已统一。
- 更多菜单采用白色克制浮层，按设置/资料、内容管理、刷新分组，使用图标、分隔线和紧凑行高。
- 话题列表、详情、回复、任务、搜索和群摘要支持按用户隔离的离线只读缓存。
- 索引死信已提供管理员查询、立即重试和删除能力，并有独立运维页面。

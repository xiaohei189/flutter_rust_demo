## 十二、消息提醒策略（Flutter 特有精细控制）

Flutter Demo 实现了最精细的消息提醒策略：

1. 全局免打扰 (`globalRecvMsgOpt == 2`) → 静默所有消息
2. 消息自身设置不推送 (`notSenderNotificationPush == true`) → 跳过
3. 正在输入的打字消息 → 跳过
4. 自己发送的消息 → 跳过
5. 系统通知消息（除入群通知外）→ 跳过
6. 单个会话免打扰 (`recvMsgOpt != 0`) → 跳过
7. 前台运行 → 播放提示音 + 震动
8. 后台运行 → 显示系统本地通知

## 十五、总结对比

| 维度 | Flutter Demo | Electron Demo | Android Demo |
|------|-------------|---------------|--------------|
| **消息类型** | 10 种 | 11 种 | 12 种（最全） |
| **群组管理** | 基础 | 中等 | 最完整（禁言/权限） |
| **多媒体** | 中等 | 中等 | 最丰富（自定义表情） |
| **音视频通话** | 基础 | 基础 | 最完整（蓝牙/浮窗） |
| **通知推送** | 最精细 | 中等 | 中等（个推） |
| **特有亮点** | 锁屏密码、精细通知策略、阅后即焚、消息自动销毁、聊天背景、草稿保存 | REST API 管理、Webhook、跨平台（含 Web）、富文本编辑、截图、系统托盘、多设备策略 | 阅后即焚、自定义表情管理、蓝牙音频、浮窗通话、群公告、群聊权限控制、Bugly 崩溃上报 |

> **三个 demo 共覆盖约 120+ 项具体功能点**，核心 IM 功能（账号、好友、群组、消息、会话、音视频通话）在三个平台均已完整实现，差异化主要体现在各平台的原生能力和特色功能上。
